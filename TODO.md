Добавить возможность прикреплять изображение к каждому шагу рецепта.

## 2. Ошибка при редактировании шагов приготовления

При сохранении шага сервер возвращает `400 Bad Request`:

```
POST /api/admin/recipes/23/steps/ HTTP/1.1 400 38
```

Предварительно первый запрос падает с `401 Unauthorized`, затем токен обновляется и повторный запрос снова возвращает `400`. Значит проблема не в авторизации, а в данных запроса.

**Что проверить:**
- Какие поля ожидает `RecipeStepCreateSerializer` и что реально отправляет фронтенд
- Возможно поле `order` не передаётся или передаётся неверный тип
- Посмотреть тело ответа `400` (сейчас в логах только код без деталей)
