# Запуск Backend — Инструкция

> Все команды выполняются из папки `server/`
> make help описание всех команд (если вывелся поломанный текст `make pwrshell_utf`)
> В `.env` не должно быть кавычек вокруг значений переменных
> ! Не забывайте сохранять добавленные в бд данные в проекте `make save_data` / `make docker_save_data`
> Если какие-то ошибки с контейнером докера, лучше его пересоздать

---

## Запуск Backend (Django, для бэкендеров)

Этот способ предполагает ручную установку Python и PostgreSQL на вашей машине. Команды зависят друг от друга — выполняйте их строго по порядку.

### 1. Создать файл окружения
```
make env
```
Копирует `.env.example` в `.env` и напоминает, какие параметры нужно заполнить.

### 2. Создать виртуальное окружение
```
make venv
```
Создаёт папку `venv` с изолированным Python-окружением.

### 3. Установить зависимости
```
make install
```
Устанавливает все пакеты из `requirements.txt` в окружение. Автоматически вызывает `make venv`, если окружение ещё не создано.

### 4. Сгенерировать SECRET_KEY
```
make secret_key
```
Генерирует случайный ключ и выводит строку `SECRET_KEY=...` в терминал. Скопируйте её и вставьте в `.env`, заменив значение по умолчанию.

### 5. Настроить базу данных

Создайте базу данных в PostgreSQL вручную или используйте существующую (**выполнять скрипт из sql не надо**). Укажите в `.env`:

- `DB_NAME` — имя базы данных
- `DB_USER` — пользователь PostgreSQL (по умолчанию обычно postgres)
- `DB_PASSWORD` — пароль (который вы указали при установке PostgreSQL)
- `DB_HOST=localhost`
- `DB_PORT=5432` (порт PostgreSQL по умолчанию, если не меняли)

### 6. Применить миграции
```
make migrate
```
Создаёт таблицы в базе данных.

### 7. Запустить сервер
```
make run
```
Запускает сервер разработки.

Сервер будет доступен по адресу: `http://127.0.0.1:8000/`

### Дополнительные команды

| Команда | Описание |
|---|---|
| `make load_data` | Загрузить фикстуры (тестовые данные) в локальную БД |
| `make save_data` | Выгрузить текущие данные из локальной БД в фикстуры |
| `make gen_data` | Заполнить БД сгенерированными тестовыми данными (пользователи, рецепты, меню, корзина) |

## Запуск Backend с помощью Docker (для фронтендеров)

Этот способ не требует установки Python или PostgreSQL — всё работает в контейнерах. Нужен только установленный десктопный Docker.

### 1. Создать файл окружения
```
make docker_env
```
Копирует `.env.example` в `.env`. Проверьте, что в файле установлено `DB_HOST=db`.

### 2. Сгенерировать SECRET_KEY
```
make docker_secret_key
```
Запускает одноразовый контейнер Python и генерирует ключ. Выводит строку `SECRET_KEY=...` в терминал. Вставьте её в `.env`, заменив значение по умолчанию.

### 3. Запустить контейнеры
```
make docker_up
```
Запускает контейнеры с Django и PostgreSQL. При первом запуске качаются образы это займет какое-то время.

После успешного запуска доступно:
- **API:** `http://localhost:8000`
- **Админка Django:** `http://localhost:8000/admin`
- **Android-эмулятор:** `http://10.0.2.2:8000` (адрес уже добавлен в `ALLOWED_HOSTS`)

### Если миграции не применились автоматически
```
make docker_migrate
```
Выполните в отдельном терминале, пока `docker_up` запущен в первом.

### Дополнительные команды

| Команда | Описание |
|---|---|
| `make docker_tables` | Посмотреть список таблиц в базе данных |
| `make docker_load_data` | Загрузить фикстуры в Docker-контейнер |
| `make docker_save_data` | Выгрузить данные из Docker в фикстуры |
| `make docker_del` | Удалить контейнеры вместе со всеми данными в БД |

> Для остановки сервера нажмите `Ctrl+C` в терминале с запущенным `make docker_up`.
